# Trabajo Práctico Integrador (TPI) — Metodología de Sistemas II

Repositorio oficial del Trabajo Práctico Integrador para la materia **Metodología de Sistemas II** de la **Tecnicatura Universitaria en Programación (TUP)** — **UTN**.

## Objetivo del Proyecto
Evaluar la aplicación integrada de los contenidos de la materia mediante el análisis y mejora de un sistema de software. El foco es evidenciar la calidad interna, identificar deuda técnica, reconocer code smells, aplicar principios SOLID y Clean Code, ejecutar refactorings seguros y realizar code review.

## Etapas Obligatorias del TPI
1. Selección y descripción del sistema base
2. Calidad externa vs. calidad interna
3. Deuda técnica y code smells
4. Aplicación de SOLID y Clean Code
5. Refactoring seguro
6. Pruebas y verificación
7. Code review profesional
8. Conclusiones y aprendizaje

## Estructura de Tags en Git
* estado-inicial: Versión base con code smells
* etapadiagnostico: Análisis de deuda técnica
* etapa-refactoring: Aplicación de SOLID
* etapa-pruebas: Verificación
* etapa-docs: Documentación y Code Review
* estadorefactorizado: Versión final limpia
